## Scope

확인한 기록은 2026년 10월 8일까지입니다. 전체 조건과 개별 실행은 부록에 보존했습니다.

| 자료 | 포함 범위 |
| --- | --- |
| iPhone | 중복을 합친 실행 146개, Unity 조건 64행, 추론 전용 정상 집단 11개 |
| 맥 기존 재집계 | 실행 182행, 이 중 RAM 수집 134행·미수집 48행 |
| 맥 별도 비교 | E2B 36회 행렬, E4B 할당 진단 4회, Swift 해시 6회 |
| 이전 탐색 | MTP와 초기 모델 비교·단독 실행, RAM 미수집과 실패 포함 |
| 정책 | iPhone 직접 카나리·외부 기기 보고·과거 할당 실험, Android 공식 정책·외부 관리 힙 로그 |

위 수는 서로 다른 단위입니다. 조건표와 실행표, 재집계와 원래 실험을 더해 총 실험 횟수를 만들지 않습니다. 실험 ID는 기록을 연결하는 임의 식별자이며 기기 식별자는 포함하지 않았습니다.

## Coverage and corrections

기존 Android 조사 원문은 확인한 연구 폴더와 프로젝트 문서 범위에서 찾지 못했습니다. 이번에 공식 문서와 직접 보고를 다시 확인한 자료를 넣었습니다. 별무리 Android 실기기 메모리 비교는 이 기록에 없습니다.

과거 E2B 맥 cold 실행은 디코드 뒤 경계 스냅샷을 포함한 정정값을 사용했습니다. 분할 프리필의 마지막 호출이 1토큰인 실행은 전체 입력 1025토큰으로 표시하고, JSON에 원래 필드와 정규화 필드를 함께 남겼습니다. SE 3의 2GB 한도 주장은 첨부 로그가 저장 공간 오류여서 미확인으로 표시했습니다.

원본 로그 전체를 새로 실행하거나 해시 검사하지는 않았습니다. 보존된 요약·CSV의 조건과 반복 수, 중앙값을 대조하고, 해당 원본을 재계산했던 기존 검증 기록을 참조했습니다. JSON에는 정수 바이트와 원본 요약의 상대 참조가 있습니다. 내부 보관함의 참조 문자열은 공개 링크가 아니며, 공개 가능한 근거 파일은 연결된 부록의 링크로 제공합니다.
