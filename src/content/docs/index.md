## How it works

대화 요청은 관련 기억과 현재 장면 정보를 모아 언어 모델에 전달합니다. 알람이나 일정처럼 기기 기능이 필요한 요청은 별도 경로로 보내고, 실행 전에 사용자의 확인을 받습니다.

```text
사용자 입력
  ├─ 대화 → 기억 검색 → 장면 정보와 함께 모델에 전달 → 답변
  │                                          └→ 기억 저장 판단
  └─ 기기 기능 요청 → 사용자 확인 → 실행
```

## Key capabilities

### Conversation

현재 장면에 맞는 정보를 모델 입력에 넣어 답변을 생성합니다.

### Memory

모든 발화를 저장하지 않습니다. 저장 여부를 판정하고, 다음 대화에서 관련 기록을 검색합니다.

### Native tools

알람과 일정 같은 요청을 기기 기능으로 연결합니다. 이 경로는 통합 검증 중이며, 실행 전에 사용자의 확인을 받습니다.

## Evaluation

기억의 저장 판정과 검색 결과를 따로 평가합니다. 실험마다 사용한 모델과 데이터, 실행 환경을 기록합니다. Mac에서 얻은 결과를 iPhone의 지연시간이나 메모리 사용량으로 해석하지 않습니다.
